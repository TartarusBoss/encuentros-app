# Encuentros App

Monorepo con backend y frontend.

## Estructura

- Encuentros-Back/
- Encuentros-Front/

## Requisitos

- Node.js LTS 20+
- npm
- PostgreSQL
- Ollama

## Ejecutar backend

```bash
cd Encuentros-Back
npm install
npm run start:dev
```

## Ejecutar frontend

```bash
cd Encuentros-Front
npm install
npm start
```

## Base de datos

Crear la base `encuentros` y luego las tablas necesarias.
